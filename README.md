# The Terrene Plane — карта Dota 2

Статический сайт: карта, 99 меток из приложенного списка, переключатель меток и координаты любой точки. Работает без сборки, сервера и внешних библиотек. Можно открыть `index.html` прямо в браузере.

## GitHub Pages

1. Распакуйте архив. Загрузите **содержимое** архива в корень своего репозитория: `index.html` должен лежать в корне, а изображение — в `assets/map.png`.
2. Откройте **Settings → Pages**.
3. В **Build and deployment → Source** выберите **Deploy from a branch**.
4. Укажите ветку с файлами (обычно `main`), папку **/(root)** и нажмите **Save**.
5. После публикации GitHub покажет адрес сайта в разделе Pages.

Все пути относительные: сайт работает и по адресу `username.github.io`, и в подпапке `username.github.io/repository/`.

[Инструкция GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Управление

- Клик или короткое касание свободной точки показывает её координаты.
- Клик по метке показывает имя и точные координаты героя из CSV.
- Переключатель «Метки героев» скрывает или показывает все метки.
- Перетаскивание перемещает карту; колесо мыши, кнопки `+`/`−` или жест двумя пальцами меняют масштаб.
- Кнопка под `−` показывает всю карту.
- Кнопка «Копировать pos» копирует `[lat, lng]` с полной точностью. На экране числа округляются до шести знаков, X/Y — до двух.
- С клавиатуры: Tab выбирает элементы; Enter активирует метку или кнопку. Когда карта в фокусе, `+`/`−` меняют масштаб, стрелки перемещают карту, Home показывает её целиком, Enter выбирает точку в центре окна карты.

## Координаты

В исходном CSV `y` — это `lat`, а `x` — это `lng`.

```js
pos = [lat, lng]
X = lng * 128
Y = -lat * 128

// Обратное преобразование для клика:
lat = -Y / 128
lng = X / 128
```

Начало координат находится в левом верхнем углу **всего изображения**, включая рамку. Логический размер карты — **17408 × 10240**, как в имени присланного файла. Масштабирование и перемещение не меняют систему координат.

Приложенная картинка фактически имеет размер **2048 × 1204**. Она отображается в логических границах 17408 × 10240: позиции героев остаются правильными, но детализация при сильном приближении ограничена. Если есть полноразмерный оригинал, замените `assets/map.png` им — менять координаты не нужно.

## Файлы и обновление героев

- `index.html` — интерфейс.
- `style.css` — оформление и мобильная раскладка.
- `app.js` — перемещение, масштабирование и выбор точки. Константы исходного размера и масштаба `128` находятся в начале файла.
- `heroes.js` — координаты героев, используемые сайтом. Для изменения меток редактируйте этот файл; поля `lat` и `lng` сохраняют систему координат из CSV.
- `heroes.csv` — копия исходного списка для справки. Изменения CSV автоматически не загружаются; сайт читает `heroes.js`, чтобы работать и при открытии локального HTML.
- `assets/map.png` — присланное изображение.
- `.nojekyll` — отключает обработку статических файлов Jekyll.

Сайт не требует API, ключей или доступа к внешним сервисам.
