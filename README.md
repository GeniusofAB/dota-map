# Dota map

Статическая карта для GitHub Pages. Шесть вертикальных полос `assets/1.jpg`–`assets/6.jpg` расположены слева направо. Сборка и внешние библиотеки не нужны.

## Где добавлять героев

Единственный список — **`heroes.js`**. Внутри `window.HEROES` добавьте строку:

```js
{ name: "Новый герой", pos: [-30.5, 70.25] },
```

`pos` всегда имеет порядок **`[lat, lng]`**. Координаты можно скопировать кнопкой в правой панели карты. Между строками списка нужна запятая.

Для временного скрытия одной метки добавьте `hidden: true`:

```js
{ name: "Новый герой", pos: [-30.5, 70.25], hidden: true },
```

`heroes.csv` удалён: это была копия исходного импорта, которую сайт не читал. Не нужно вести два списка или выполнять преобразование CSV.

## Координаты и управление

```js
X = lng * 128;
Y = -lat * 128;
```

Логический размер — 17408×10240, начало в левом верхнем углу всей карты. Шесть полос по 2901 пикселю отображаются в этих границах; система координат сохранена.

Клик выбирает точку, перетаскивание перемещает карту, колесо мыши или жест двумя пальцами меняет масштаб. Кнопки слева: метки, приближение, отдаление, вся карта. Панель справа показывает только имя выбранного героя и координаты. Надписи внутри изображения карты являются частью самой картинки.

С клавиатуры: Tab перемещает фокус, Enter активирует кнопку или метку. В фокусе карты стрелки перемещают её, `+`/`−` меняют масштаб, Home показывает всю карту, Enter выбирает её центр.

## Публикация

GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root). Изменения в `main` публикуются автоматически.
